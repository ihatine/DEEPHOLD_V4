# DEEPHOLD v1.2

Основа: Unity 6000.0.59f1.

## Что добавлено

- Более аккуратное главное меню.
- Одиночная игра.
- Раздел Multiplayer: Host / Join по IP.
- NetworkManager остаётся корневым объектом, поэтому старая ошибка nested NetworkManager не используется.
- Детерминированная генерация поверхности с фиксированным seed: одинаковый мир на host/client.
- Защищённая стартовая зона и гарантированный сухой маршрут к пещере.
- Деревья и ресурсы размещаются только на допустимой поверхности и с минимальной дистанцией друг от друга.
- Дерево нельзя добывать рукой — нужен деревянный топор.
- Камень, медь и кристалл нельзя добывать рукой — нужна деревянная кирка.
- Деревянный меч используется для атаки существ ПКМ.
- Инструменты доступны с самого начала: 1 топор, 2 кирка, 3 меч.
- При удержании ЛКМ над ресурсом появляется прогресс добычи и процент.
- При неправильном инструменте HUD сообщает «НУЖЕН ТОПОР» или «НУЖНА КИРКА».
- Мобы получили HP и могут погибнуть от меча.
- HUD получил отдельную панель текущего инструмента и 8 слотов.

## Управление

WASD — движение
1 — деревянный топор
2 — деревянная кирка
3 — деревянный меч
ЛКМ — добыча / удерживать для разрушения ресурса
ПКМ — удар мечом
F — вход/выход из пещеры
I — инвентарь

## Multiplayer

1. Один игрок нажимает Multiplayer → Create Server.
2. Второй вводит IP хоста → Connect.
3. Для локальной проверки на одном ПК можно использовать 127.0.0.1, но для двух ПК нужен LAN-IP хоста и открытый UDP-порт 7777.
