# DEEPHOLD v1 — changes

- Original pixel-art DeepMiner character, 4 directions × 4 frames.
- Runtime sprite animation, no Animator Controller dependency.
- Chunked 16×16 world rendering.
- Local chunk rebuild on mining/building.
- Large trees, copper veins, crystal clusters, mushrooms, torches, water and core.
- Expanded inventory: Wood / Stone / Torch / Copper / Crystal / Food.
- Updated HUD and 8-slot hotbar.
- Reduced world GameObject count drastically compared with the per-tile prototype.
- Singleplayer remains the safe test mode; Netcode code is retained for later co-op integration.
