# DEEPHOLD — v1.0 CHARACTER + CONTENT + OPTIMIZATION

База: Unity 6.0.0f1 / 6000.0.59f1.

## Что добавлено

### Персонаж
- Новый оригинальный пиксельный персонаж-разведчик.
- 4 направления: вниз / влево / вправо / вверх.
- 4 кадра на направление.
- Idle + walk-анимация без Animator Controller.
- Point filtering для чёткого pixel-art.
- Персонаж создаётся автоматически через `PlayerFactory`.

### Мир
- Пол больше не состоит из тысяч отдельных GameObject.
- Мир разбит на чанки 16x16.
- Каждый чанк строится как Mesh с несколькими материалами.
- Добыча/установка блока перестраивает только затронутый чанк.
- Большие деревья сделаны отдельными компактными объектами.
- Добавлены:
  - медные жилы;
  - кристаллические залежи;
  - грибные/пищевые узлы;
  - грибы-декорации;
  - большие деревья;
  - факелы и локальный свет;
  - вода;
  - центральное ядро.

### UI
- Обновлён HUD.
- Добавлена горячая панель на 8 слотов.
- Показываются Wood / Stone / Copper / Crystal / Food / Torch.
- Меню и экран загрузки сохранены.

## Оптимизация

Старый вариант создавал отдельный GameObject практически для каждой клетки мира.
Новый вариант держит поверхность мира в небольшом количестве Mesh-чанков.
Интерактивными остаются только объекты, которым реально нужны отдельные компоненты.

Это база для дальнейшего:
- стриминга чанков;
- Fog of War;
- сохранения изменённых чанков;
- процедурных биомов;
- кооперативной синхронизации только изменённых чанков.

## Важно

Текущий прототип остаётся singleplayer-first.
Сетевой слой Netcode сохранён в проекте, но новые ресурсы и персонаж сейчас рассчитаны прежде всего на стабильное одиночное тестирование.

## Запуск

Открывать через Unity 6000.0.59f1.
После импорта открыть сцену `Assets/OutOfSync/Scenes/TestScene.unity` и нажать Play.
