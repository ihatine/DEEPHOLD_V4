# DEEPHOLD — v1.1 SURFACE + CAVES

База: **Unity 6.0.0f1 / 6000.0.59f1**.

## Главные изменения

### Поверхность
- Поверхностная земля теперь **неразрушаемая**.
- ЛКМ больше не удаляет клетки поверхности.
- Поверхность используется для исследования, строительства будущей базы и поиска входов в подземелья.
- Деревья теперь являются полноценными ресурсными объектами: ЛКМ по стволу даёт Wood и удаляет дерево.
- Деревья увеличены и сделаны заметнее на дистанции.

### Пещеры и шахта
- На поверхности появился заметный **Cave Entrance**.
- Вход можно использовать ЛКМ или клавишей **F**, если игрок находится рядом.
- После входа игрок переносится в отдельную подземную шахту.
- Подземелье содержит:
  - каменные залежи;
  - медную руду;
  - кристаллы;
  - мох/декор;
  - пещерных ползунов.
- В шахте есть обратный выход.
- Подземный слой отделён от поверхности, поэтому поверхность не превращается в дырявый Terraria-подобный массив.

### HUD
- Переработан HUD: статус персонажа слева, текущая зона и HP, objective справа, hotbar снизу.
- **I** открывает полноценное окно инвентаря.
- В HUD отображаются Wood / Stone / Torch / Copper / Crystal / Food.
- Objective автоматически меняется между Surface и Deep Mine.

### Оптимизация
- Поверхность продолжает использовать mesh chunks вместо GameObject на каждую клетку.
- Интерактивными остаются только деревья, ресурсы, входы и существа.
- Земля больше не перестраивается при каждом клике мыши.
- Подземная зона строится отдельным набором объектов и активируется только при входе.

## Управление

- **WASD** — движение
- **ЛКМ** — собрать ресурс / войти в пещеру
- **F** — использовать ближайший вход/выход
- **ПКМ** — зарезервировано под будущую систему строительства
- **I** — инвентарь
