# DEEPHOLD — 2.5D Survival Prototype

Текущий прототип переориентирован с Terraria-подобного side-scroller на **2.5D top-down survival sandbox** в духе Core Keeper.

## Текущий билд
- Unity 6 / 6000.0.59f1
- Singleplayer-first
- процедурно создаваемое тестовое поле
- большой центральный Core
- крупные деревья
- вода и разные типы поверхности
- движение WASD / стрелками в плоскости XY
- ЛКМ — добыча
- ПКМ — установка блока
- главное меню
- экран загрузки/инициализации
- базовый HUD
- Netcode остаётся в проекте как фундамент для будущего кооператива, но NetworkManager не запускается автоматически

## Важно
Это не финальный арт. Геометрия мира сейчас runtime-generated placeholder. Следующий этап — заменить кубы на нормальные tile/sprite/2.5D assets, добавить инвентарь, крафт, строительство, врагов, сохранение мира и затем сетевую репликацию.


## v0.5 — stable singleplayer / shader fix
- Убрана зависимость от `AmbientMode`, из-за которой Unity 6 в текущей конфигурации останавливал компиляцию.
- В рантайме используется одиночный режим без автоматического запуска Netcode.
- Увеличены деревья: ствол 10–13 тайлов, крона заметно крупнее.
- Исправлен `ArgumentNullException (shader)` при создании игрока: фабрика больше не требует URP-шэйдеров и использует материал встроенного рендера.
- Главное меню и экран инициализации оставлены перед стартом мира.
- Целевая версия проекта: Unity 6000.0.59f1.

ВАЖНО: Unity компилирует C#-скрипты до входа в Play Mode. Экран запуска в проекте — это инициализация мира, а не компиляция C# во время игры.
